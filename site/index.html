03 / HOW IT WORKS

Explore first.
Understand deeper.

This is an independent, open educational project. Each course website can pair explanations with direct manipulation: change an input, follow the intermediate state, and see the reasoning behind an answer.

Examples and general concepts can be studied anytime. Instructor-provided homework solutions appear only when they are officially released and sharing is authorized.
