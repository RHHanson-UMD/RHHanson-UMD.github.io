Math basics

Fast checks for algebra and calculus manipulations.

Differentiate a composition

Chain rule: differentiate the outside, keep the inside, then multiply by the derivative of the inside.

d/dx f(g(x)) = f'(g(x)) g'(x)

Check: d/dx (3x² + 1)⁴ = 24x(3x² + 1)³. The missing 6x is a classic mistake.

Refresh: Paul's Online Math Notes

Use substitution in an integral

  1. Look for an inner expression and its derivative.
  2. Set u = g(x) and replace du = g'(x)dx.
  3. Integrate in u; substitute back (or change definite bounds).
∫ 2x cos(x²) dx = sin(x²) + C
Refresh: UMD mathematics notes

Rearrange equations safely

Write down where denominators are zero before multiplying through; squaring both sides can introduce extraneous solutions.

(x² − 1)/(x − 1) = x + 1, but x ≠ 1

Always substitute candidate answers into the original expression.

Refresh: Common Errors in Undergraduate Mathematics

Recognize a sequence

Try first differences, second differences, ratios, and simple recurrences before guessing a formula. A finite sample never uniquely identifies a sequence.

2, 5, 10, 17 → differences 3, 5, 7

The rule a(n) = n² + 1 fits for n = 1, 2, 3, 4, but other rules fit too.

Linear algebra

Operations that reappear in engineering, optimization, and ML.

Check matrix dimensions

If A is m × n and B is n × p, then AB is m × p. The inner dimensions must agree.

A (2×3) · B (3×4) → AB (2×4)

Matrix multiplication generally does not commute: AB ≠ BA.

Refresh: UMD mathematics notes

Find eigenvalues and eigenvectors

  1. Solve det(A − λI) = 0 for eigenvalues λ.
  2. For each λ, solve (A − λI)v = 0.
  3. Check Av = λv and v ≠ 0.

For a diagonal matrix diag(2, 3), the coordinate axes are eigenvectors with eigenvalues 2 and 3.

Probability & signals

General prerequisite reminders; course-specific conventions belong on the course sites.

Use Bayes' rule

P(A|B) = P(B|A) P(A) / P(B)

First identify the conditioning event and confirm P(B) > 0. Don't interchange P(A|B) and P(B|A).

Example: 1% prevalence, 90% sensitivity, 10% false-positive rate gives 0.009/(0.009 + 0.099) ≈ 8.33% probability after a positive result.

Related foundations: Paul's Online Math Notes (math refresher)

Check sampling before interpreting a spectrum

For a bandlimited continuous-time signal with highest frequency fmax, ideal reconstruction requires a sampling rate fs > 2fmax (with suitable assumptions).

f = 700 Hz, fs = 1 kHz → alias at 300 Hz

Label whether the horizontal axis is Hz, rad/s, or rad/sample. A sampled spectrum is periodic in frequency.

Programming

Small commands and habits worth keeping at hand.

Create a Python virtual environment

python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Linux/macOS
source .venv/bin/activate
python -m pip install PACKAGE

Use python -m pip so package installation targets the Python interpreter you intended.

Remember the everyday Git loop

git status
git switch -c feature/my-change
git add path/to/file
git commit -m "Describe the change"
git push -u origin feature/my-change

Review the diff before committing. Open a pull request rather than pushing unreviewed changes directly to the default branch.

Iterate with indices or pairs

for i, value in enumerate(values):
    print(i, value)

for x, y in zip(xs, ys):
    print(x, y)

enumerate gives (index, value); zip pairs iterables and stops at the shortest by default.

Pass C++ containers without copies

void inspect(const std::vector<int>& values) {
    for (int value : values) {
        // inspect value
    }
}

const & avoids a container copy and prevents modification through that reference. Include <vector>.

Machine learning

Useful checks before trusting a model or its evaluation.

Recall gradient descent

θ(next) = θ(now) − η ∇L(θ(now))

η is the learning rate. Too large can cause divergence; too small can stall progress. Check whether the loss goes down on a simple known example.

Refresh: Dive into Deep Learning

Avoid data leakage

  1. Split training, validation, and test data appropriately.
  2. Fit preprocessing steps on training data only.
  3. Use validation data for selection; evaluate the final model on held-out test data.

For time series, respect chronology; for grouped observations, avoid allowing the same group into both training and test sets.

Research & writing

Find sources and turn them into defensible, traceable explanations.

Build a reliable citation

Record author, year, exact title, publisher or journal, and DOI/URL when applicable while reading. Then format according to the required citation style and verify it against the original source.

A generator is a starting point, not an authority; check capitalization, editions, page ranges, and missing metadata.

Check AI and source-use rules

Before using AI tools for coursework, read the applicable course and university policies. Keep confidential materials private, cite verifiable claims, and distinguish your analysis from generated suggestions.

Rebuild intuition for 3D rotations

Quaternions compactly describe spatial rotations. Keep component order and coordinate conventions explicit; when using a unit quaternion, its inverse is its conjugate.

A rotation demonstration helps distinguish changing a vector's coordinates from rotating the physical vector.
